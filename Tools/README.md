# Tools

End-to-end checks on the real screen. Not shipped in the app, and not run by `scripts/check`, because they switch apps and dim the display.

- **`./e2e.sh`** runs the real DimmingEngine, GammaController, ActivationMonitor and FrontWindowTracker, switches between Terminal and Finder, and reads every result back with `peek`. It then checks the safety net through the real `SafetyNet` and watchdog (built straight from `App/GammaWatchdog`): termination signals, `kill -9`, main-thread stalls under 1 s, the watchdog's idle CPU, `kill -STOP` restored within 2 s and faded back on `kill -CONT`, and a killed watchdog being replaced. It prints `ok` or `FAIL` per step, plus the harness logs if anything failed, and exits non-zero on any failure. It takes about a minute, and refuses to start while Cathemeral is running, because a second gamma writer spoils the readings.
- **`switch-timing`** (`swift run switch-timing <bundle-id> <bundle-id> [rounds]`) switches between two apps and fails if either app is ever shown brighter than its own level (brightening must wait until the new app's window is in front, and dimming must be done by then), if a switch jumps instead of fading, or if rapid switching back and forth ever jumps. Run it while Cathemeral or the harness is dimming, with different levels for the two apps. `e2e.sh` runs it. It never writes gamma.
- **`peek`** (`swift run peek [--built-in]`) prints each display's gamma peak: about 1.0 undimmed, about the level when dimmed. `peek --built-in --until 1.0000 --within 2` waits for that peak and prints how many milliseconds it took. It never writes gamma, so running it changes nothing.
- **`harness`** is the engine with no UI (plus the activation monitor and window tracker), driven by commands on stdin (`set`, `activate`, `hide`, `displays-changed`, `suspend`, `unsuspend`, `stall`, `quit`). Run it as `harness <path-to-GammaWatchdog>`: like the app, it keeps a watchdog through `SafetyNet`. The command list is at the top of `Sources/harness/main.swift`. Extend `e2e.sh` with new scenarios as tickets add behaviour (ramps, handover, displays, signals).

Both `e2e.sh` and `harness` follow the gamma-safety standards in `CODING_STANDARDS.md`: every way out ends the harness, whose exit makes macOS reset its gamma.
